# 《库尔之河》SillyTavern 资源包

基于小说《库尔之河》第二世（W2）开篇制作的 ST 资源：bot 扮演**阿贝尔**，用户扮演**凉**，场景从木屋清晨开始。

## 文件清单

| 文件 | 用途 | ST 导入方式 |
|---|---|---|
| `阿贝尔.png` | PNG 角色卡（带立绘，推荐） | 角色面板 → 导入角色（Import Character），直接选这个 PNG |
| `阿贝尔-角色卡.json` | 角色卡（Chara Card V2，JSON 版） | 同上；与 PNG 卡内容一致，二选一即可 |
| `库尔之河-世界书.json` | 世界书（World Info，30 条） | 世界书面板 → 导入（Import），然后绑定到角色卡或设为全局 |
| `凉-用户persona.md` | 用户 persona 文本 | 用户头像面板 → 新建 persona，把全文粘进描述框 |
| `库尔之河-西幻文风正词表.json` | Regex 扩展脚本（29 条，4 组） | 扩展面板 → Regex → 导入（Import） |
| `西幻文风正词表-说明.md` | 正词表逐条说明与激进规则标注 | 不导入，仅供查阅 |
| `对话模板.md` | 原文对话轮次摘录（20 段，含出处行号） | 不导入，调教文风/写提示词时参考 |

## 使用建议

- **角色卡**：PNG 卡与 JSON 卡内容相同，PNG 内嵌立绘（`W2木屋重逢-晨光.png`），建议直接用 PNG。卡片由 `scripts/build-st-card.js` 生成，改了 JSON 后重跑该脚本即可同步 PNG。
- **世界书绑定**：建议绑定到阿贝尔角色卡（角色卡 → 关联世界书），而不是全局，避免串戏。条目已配好触发词，其中两条常驻条目（"第二世当前状态""第一世大事记"）设为 constant，防止模型提前剧透相认与第一世终局。
- **扫描深度**：条目 depth 均为 4，默认即可；如用递归扫描，保持默认。
- **正词表**：只作用于 AI 输出（placement=[2]），按"现代词/修仙武侠腔/日式腔/宗教违和"拆成 4 组，可整类开关；标 ⚠️ 的激进规则有误伤可能，按需单独关闭，详见说明文档。
- **采样**：文风偏小说体（动作描写＋极简对话），建议温度 0.8–1.0；若模型回复过短，可把回复长度上限调高一些。
- **备选开场**：角色卡自带一条第一世（W1）开篇版 alternate greeting——阿贝尔在木屋醒来、推门看见浇玉米的凉，对应原作 1.txt 开头。
- 世界书条目标注"【W2设计方向】"的内容来自设计讨论笔记，属尚未正式落稿的设计方案，仅供参考走向，非既定事实。

## W1 重跑包（第一世）

从第一世开篇重玩：阿贝尔坠海获救、在库尔木屋初遇凉，之后才是并肩作战、叛乱、加冕的主线。

| 文件 | 用途 |
|---|---|
| `阿贝尔-W1.png` / `阿贝尔-W1-角色卡.json` | W1 阿贝尔卡（木屋初醒开局），底图：杜鹃花海夜宿 |
| `凉-W1.png` / `凉-W1-角色卡.json` | W1 凉卡（施救方开局，description 含本人不知情的身世伏笔），底图：麦田上空的龙骑士 |
| `丽希娅-W1.png` / `丽希娅-W1-角色卡.json` | W1 丽希娅卡（first_mes 为魔山垭口重逢，前期靠通信石板出场），底图：最后的温柔-玻璃花房茶会 |
| `库尔之河-世界书-W1.json` | W1 版世界书（30 条）：常驻条换成"第一世当前状态（防剧透）"与"开局前情"，全部条目改为纯 W1 视角，无 W2 设计方向内容 |

建议用法：

- **组群聊**：三张卡一起加进群聊，绑定 `库尔之河-世界书-W1.json`，模型分饰三角。
- **自己演凉**：别加凉卡，只加阿贝尔卡＋丽希娅卡，配合 `凉-用户persona.md`。
- **不要混绑**：W1 世界书与 W2 世界书（`库尔之河-世界书.json`）不要同时绑定同一群聊/角色，两版常驻条互相冲突。
- PNG 卡由 `scripts/build-st-card.js <卡json> <底图png> <输出png>` 生成；不带参数时仍生成 W2 阿贝尔卡。
